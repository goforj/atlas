Add a typed client for the configured tax-rate service under `internal/taxrates`. Its public boundary is `NewClient(baseURL string)` with `Find(ctx, country string) (Rate, error)`. The remote service exposes `GET /rates/{country}`, where the country is URL-path escaped, and returns JSON shaped as `{"country":"US","percent":7.25}`. Add `provideTaxRateClient` to read the base URL from App configuration and construct the client. Propagate caller cancellation, return useful error context, and test the remote contract with a local HTTP server rather than the external network.
